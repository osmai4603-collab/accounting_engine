# حزمة مهارتَي التخطيط وسلامة التنفيذ

تحتوي هذه الحزمة على مهارتين منفصلتين، لكل منهما مسؤولية محددة:

1. `execute-plan-lifecycle/SKILL.md` — تخطيط دورة حياة التنفيذ: المراحل والمهام والاعتماديات والتوازي وحالات المهام وتقارير ARD واعتماد المراحل.
2. `execution-safety/SKILL.md` — سلامة التنفيذ: حماية المستودع وGit، حماية التغييرات السابقة، حدود النطاق والملكية، التعافي بعد الانقطاع، جودة الأدلة، المراجعة المستقلة، والدمج الآمن.

## طريقة استخدامهما معًا

- عند إنشاء خطة أو تحديث هيكلها أو متابعة حالاتها، استخدم `execute-plan-lifecycle`.
- قبل أي تعديل فعلي في ملفات المشروع، استخدم `execution-safety`.
- عند تنفيذ مهمة ضمن خطة: تتحقق مهارة دورة الحياة من الاعتماديات والنطاق أولًا، ثم تحيل فحوصات المستودع والتنفيذ إلى مهارة سلامة التنفيذ.
- بعد التنفيذ، تسلّم مهارة سلامة التنفيذ الأدلة والنتائج والنواقص. تستخدمها مهارة دورة الحياة لإنشاء تقرير ARD وتحديث الحالة.
- عند الدمج أو اعتماد مرحلة، تعمل المهارتان بالتكامل: سلامة التنفيذ تفحص Git والدمج والأدلة، ودورة الحياة تسجل القرار وتحدّث الخطة.

## فصل الصلاحيات

| النشاط | المهارة المالكة |
| --- | --- |
| إنشاء الخطة وتقسيم المراحل والمهام | `execute-plan-lifecycle` |
| رسم الاعتماديات ومجموعات التوازي المرشحة | `execute-plan-lifecycle` |
| فحص Git وحماية التغييرات السابقة | `execution-safety` |
| تنفيذ التغييرات ضمن النطاق | `execution-safety` |
| التعافي بعد انقطاع التنفيذ | `execution-safety` |
| جودة الأدلة والمراجعة المستقلة | `execution-safety` |
| تحديث حالة المهمة وإنشاء ARD | `execute-plan-lifecycle` |
| اعتماد المرحلة | `execute-plan-lifecycle` بعد أدلة `execution-safety` |

يمكن استخدام `execution-safety` منفردة لمهمة لا تتبع خطة، بشرط تحديد النطاق ومعايير التحقق قبل التعديل.
