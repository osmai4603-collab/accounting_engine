# مهارة تقييم محركات المحاسبة (Accounting Engine Evaluation Skill)

دليل تشغيلي ومهارة معتمدة لوكلاء الذكاء الاصطناعي والمراجعين لتقييم أي محرك محاسبي بطريقة منهجية قائمة على الأدلة.

## الملفات الأساسية

- [`SKILL.md`](file:///home/osm/StudioProjects/cashflow_system/accounting_engine/.agnets/skills/accounting_engine_evaluation/SKILL.md): نص المهارة الكامل والقواعد التشغيلية الموجهة للوكيل.
- المرجع المعياري الكامل: [`docs/accounting_engine_evaluation_standard.md`](file:///home/osm/StudioProjects/cashflow_system/accounting_engine/docs/accounting_engine_evaluation_standard.md).

## الخصائص الرئيسية

1. **عامة ومستقلة عن أي مشروع**: صالحة لتقييم أي محرك محاسبي بغض النظر عن المنظومة أو بيئة العمل.
2. **قائمة على الأدلة (Evidence-Based)**: المتطلب ← التنفيذ ← الدليل (الربط الثلاثي).
3. **خمسة مراجع دولية معتمدة**: ISO/IEC 25010:2023, ISO/IEC 25040:2024, IFRS Framework, NIST SSDF, Architecture Principles.
4. **دورة تقييم من 8 مراحل** و **12 بُعد تقييم**.
5. **مقياس نضج خماسي (0-4)** وتصنيف مخاطر مستقل (Critical, High, Medium, Low).
6. **10 قواعد نزاهة إلزامية** تمنع التقييم الانطباعي أو غير الموثق.
