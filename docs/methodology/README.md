# المنهجية الهندسية العامة لبناء المحركات البرمجية (Engineering Methodology)

يقدم هذا القسم الإطار المفاهيمي والهندسي العام لتصميم المحركات البرمجية، والمبادئ المعمارية الحاكمة (مثل Clean Architecture وSOLID وDDD)، ومعايير الجودة الدولية (ISO/IEC 25010)، ومقاييس الاختبار وقوائم التحقق.

> [!NOTE]
> هذا القسم يمثل دليلاً إرشادياً ومنهجياً عاماً للمهندسين والمعماريين، بينما توجد مواصفات ومعمارية النواة المحاسبية الخاصة بهذا المستودع في مجلد [`docs/architecture/`](../architecture/) ومجلد [`docs/accounting/`](../accounting/).
