# `ARD-P1-01` — جرد العقد العام ومنع تسرب `internal`

- **المهمة:** `P1-01`
- **المرحلة:** `P1`
- **تاريخ الإتمام:** 2026-11-14
- **الحالة عند الإغلاق:** منفذة

## 1. كيف تم التنفيذ

- إنشاء `docs/public_api_inventory.md` من `go list` و`go doc` الفعليين، مع تصنيف
  سبعة مستويات (API, SPI, نقطة دخول, قوالب, موائمات مرجعية, مهمَل, داخلي).
- إضافة `docs/api/v1.snapshot` (968 سطرًا) يغطي كل رمز مصدَّر وحقوله وتواقيعه.
- توسيع `scripts/check_public_api_purity.sh`:
  - منع استيراد `internal` في `pkg/api/**` و`pkg/spi/**`؛
  - فحص `scripts/internalapi` على الجذر و`pkg/**` و`storage/**` لرفض أي نوع داخلي
    في API مصدَّر (وليس مجرد مسار نصي)؛
  - `--self-test` يبني وحدة مؤقتة ويحقن مخالفتين ويتأكد من اكتشافهما.
- نقل `CoreLedgerStore` و`LedgerApplication*` إلى `pkg/spi/legacy` المهمَل، بحيث
  أصبح `pkg/spi/storage` عقود Ports فقط بلا Post/Reverse/إنشاء Service.
- نقل تنفيذ الموائمات إلى `internal/adapters/{memory,postgres}`، وترك واجهات
  `storage/{memory,postgres}` العامة صغيرة لا تعرض `pgx` أو أنواعًا داخلية.
- إنشاء `ADR-0007` لتفسير حدّ الاستيراد: عقود نظيفة، حزم تركيب تسمح بـ`internal`
  بشرط عدم تسرب الأنواع.

## 2. إثبات معايير القبول

| معيار القبول | الدليل | النتيجة |
| --- | --- | --- |
| وجود `docs/public_api_inventory.md` | الملف يحتوي 15 حزمة و968 رمزًا مصدَّرًا | محقق |
| فحص النقاء يغطي كل الحزم العامة | السكربت يفحص `pkg/api`, `pkg/spi`, root, `pkg/**`, `storage/**` | محقق |
| يفشل الفحص عند تسرب `internal` في تجربة معزولة | `./scripts/check_public_api_purity.sh --self-test` ينجح ويتضمن مخالفتَي import ونوع مصدَّر | محقق |
| كل نوع عام له غرض وتوافق موثقان | جدول الغرض/المالك/الثبات في الجرد + `docs/api/v1.snapshot` | محقق |

## 3. النواقص

- `pkg/sdk/templates` مصنّف تجريبيًا؛ لا يُعد عقدًا محاسبيًا ثابتًا.
- `pkg/spi/masterdata.Store` يجمع القراءة والكتابة؛ فصله الكامل مهمة `P2`.

## 4. ملاحظات

- أداة `scripts/internalapi` ترفض الأنواع الداخلية في الحقول المصدَّرة والتواقيع
  والواجهات والأنواع المركبة، ولا تعتمد على اسم الحزمة النصي.
- `scripts/check_api_compat.sh` يبني على الجرد ليكتشف أي حذف/تغيير توقيع لاحقًا.
