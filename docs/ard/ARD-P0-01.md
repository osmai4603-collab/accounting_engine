# `ARD-P0-01` — اعتماد حدود المنتج ونطاق الإصدار الأول

- **المهمة:** `P0-01`
- **المرحلة:** `P0`
- **تاريخ الإتمام:** 2026-11-14
- **الحالة عند الإغلاق:** منفذة

## 1. كيف تم التنفيذ

- الالتزام بحدود التوازي: لم يُعدّل أي كود تنفيذي؛ العمل وثائقي بالكامل.
- فحص الخدمات الحالية من `internal/*` و`pkg/*` و`cmd/*` وتصنيفها.
- تحديث `docs/product_boundary.md`:
  - تعريف المنتج وحدوده.
  - جدول تصنيف 17 قدرة ضمن `core-required` / `optional` / `host-owned` / `host-hidden`.
  - الحد الأدنى للإصدار الأول (10 بنود).
  - قائمة صريحة بالميزات المجمدة (5 بنود + استثناء إصلاح العيوب).
  - معايير Industry/Infrastructure/External Consumption.
  - **قسم جديد:** مراجعة النطاق مقابل التجارة والزراعة والصناعة والخدمات مع دليل عدم تسرب القطاع إلى Core.
  - قرارات لم تُحسم أُحيلت إلى ADRs (تم حسمها في P0-04).
