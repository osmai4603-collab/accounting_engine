# معايير التقارير المالية والمحاسبية الدولية (Accounting Standards & Frameworks)

يقدم هذا القسم التوصيف الفني والمعياري للقوائم المالية والمعايير المحاسبية العالمية المنظمة لها (IFRS, US GAAP, AAOIFI, IPSAS)، مع التركيز على انعكاسها في معمارية النواة المحاسبية (`accounting_engine`).

## الفهرس المعياري

| المعيار / الوثيقة | النطاق والمحتوى |
|---|---|
| [القوائم المالية الأساسية وفق IFRS/IAS](./ifrs_core_financial_statements.md) | مواصفات قائمة المركز المالي، الدخل، التدفقات النقدية، والتغيرات في حقوق الملكية ومعادلاتها الحاكمة. |
| [هيكل العرض والإفصاح وفق IFRS 18](./ifrs18_presentation_structure.md) | المعيار الدولي الجديد لعرض القوائم، وتصنيف الأنشطة التشغيلية والاستثمارية والتمويلية ومقاييس الإدارة. |
| [معايير المحاسبة المالية الإسلامية (AAOIFI)](./aaoifi_islamic_accounting.md) | متطلبات القوائم المالية للمؤسسات المالية الإسلامية، حسابات الاستثمار المقيدة وغير المقيدة، والزكاة. |
| [فروق المعايير الأمريكية (US GAAP)](./us_gaap_reconciliation.md) | مقارنة معايير ASC الأمريكية مع IFRS وفروق الاعتراف والقياس المحاسبي. |
| [محاسبة القطاع العام والحكومي (IPSAS)](./ipsas_public_sector.md) | معايير المحاسبة الدولية للقطاع العام والتحول من الأساس النقدي إلى أساس الاستحقاق. |
| [المرجع الموسوعي الكامل للقوائم المالية](../global_financial_statements_standards_reference.md) | الدليل الموسوعي الشامل لجميع الأطر والقوانين الرياضية والمعايير الرقمية (XBRL). |
