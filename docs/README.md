## العلاقة بين المنهجية والمشروع

وثائق المنهجية العامة تحدد **كيف** يُبنى أي محرك، ووثائق المشروع توثق **ما حدث فعلاً** عند تطبيقها على محرك المحاسبة: الخطة التنفيذية تحوّل مراحل الإطار الهندسي إلى عمل ملموس، وتقارير التحقق تقيس النتائج مقابل خصائص الجودة في ISO 25010، ومطابقة المعايير تربط المشكلات المكتشفة بالمعايير الدولية ذات الصلة.
