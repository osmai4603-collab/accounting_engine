# تقرير جاهزية الإصدار وقرار Go/No-Go — P7-05

- **تاريخ التقييم:** 2026-11-16
- **النطاق:** جاهزية المنتج في المستودع الحالي؛ لا يشمل نشرًا أو اعتمادًا لبيئة إنتاج بعينها.
- **النتيجة:** **NO-GO للإصدار/النشر الإنتاجي حاليًا**
- **درجة الأدلة الموزونة:** **76.25%**؛ مؤشر وصفي، وليس شرط قبول أو شهادة.
- **المراجع التنفيذية:** [تقرير تكافؤ العقود](./contract_parity_report.md)، [ملاحظات CI](../ci.md)، [حدود المنتج](../product_boundary.md)، و[ARD-P7-05](../ard/ARD-P7-05.md).

## 1. منهج التقييم والأوزان

لا تفرض أطر ISO أو NIST المستخدمة أدناه أوزانًا رقمية موحدة أو حدًا عامًا لقرار الإصدار. الأوزان التالية هي قرار تقييم خاص بهذا المنتج، اعتمدها مالك المشروع لهذه المراجعة؛ وهي تنظّم مقارنة الأدلة ولا تنشئ ادعاء امتثال.

تُمنح كل فئة نسبة استحقاق وفق الحالة المدعومة بالدليل: مكتملة ضمن النطاق = 100%، جزئية = 50%، تحتاج تحققًا فعليًا = 25%، وغير موجودة/غير منفذة = 0%. الدرجة الموزونة هي مجموع (وزن الفئة × نسبة استحقاقها). يجري تصنيف كل وظيفة أيضًا بحالات الخطة الوظيفية، وتبقى المتطلبات غير المدعومة أو غير المنطبقة معلنة ولا تُخفى داخل الدرجة.

| مجال التقييم | الوزن | الحالة في النطاق المختبر | الاستحقاق | المساهمة |
| --- | ---: | --- | ---: | ---: |
| سلامة المحاسبة والترحيل والعكس وIdempotency | 25% | مكتملة ضمن النطاق المختبر | 100% | 25.00 |
| عزل الشركات والأمن | 20% | جزئية: اختبارات عزل الشركات ناجحة؛ فحوص Security/SBOM والمراجعة الأمنية المستقلة غير مثبتة | 50% | 10.00 |
| API/SPI والاستهلاك الخارجي | 15% | مكتملة ضمن النطاق المختبر | 100% | 15.00 |
| موثوقية التخزين والتكافؤ | 15% | مكتملة لسيناريوهات التكافؤ الدلالي المحددة؛ قدرات التخزين تختلف ومعلنة | 100% | 15.00 |
| التشغيل والاستعادة وتهيئة الإنتاج | 10% | جزئية: فحوص التهيئة والترحيل موجودة؛ الاستعادة الفعلية/PITR غير مثبتة | 50% | 5.00 |

لا يوجد حدّ رقمي يحوّل هذه النتيجة إلى Go. فشل أو غياب دليل لبوابة إلزامية أو اعتماد مطلوب يمنع Go مهما ارتفعت الدرجة.

### أساس اختيار الأوزان من المصادر الرسمية

- **NIST SP 800-30 Rev. 1** يوجّه إلى تقييم المخاطر وتقديم معلومات للمسؤولين لاتخاذ الإجراء؛ يدعم ترتيب المخاطر بحسب الأثر، ولا يحدد أوزان إصدار موحدة: [Guide for Conducting Risk Assessments](https://csrc.nist.gov/pubs/sp/800/30/r1/final).
- **NIST SP 800-53A Rev. 5** يصف إجراءات تقييم ضوابط قابلة للتخصيص وفق احتياج المؤسسة وتحملها للمخاطر؛ لا يفرض نسبة مئوية موحدة: [Assessing Security and Privacy Controls](https://csrc.nist.gov/pubs/sp/800/53/a/r5/final).
- **NIST SP 800-218 SSDF v1.1** يحدد ممارسات تطوير برمجيات آمنة مشتركة، لا درجة أو أوزان Go/No-Go: [Secure Software Development Framework](https://csrc.nist.gov/pubs/sp/800/218/final).
- **ISO/IEC 25010:2023** يقدم نموذج خصائص جودة للمنتج لتحديد الجودة وقياسها وتقييمها؛ لا يقرر أوزانًا ملزمة لهذه المحركات: [Product quality model](https://www.iso.org/standard/78176.html).

وعليه، فإن الأوزان المحددة أعلاه حكم منتج خاص: أعطت أعلى وزن لصحة المعالجة المحاسبية، ثم عزل الشركات، ثم قابلية الاستهلاك والتخزين، مع عدم السماح لأي منها بتجاوز بوابات القبول أو نقص الموافقات.

## 5. Known Limitations وUnsupported Standards Requirements

1. لا يوجد تمرين مثبت لاستعادة Backup فعلية أو PITR؛ أهداف RPO/RTO وسياسة التشغيل لا تثبت نجاح الاستعادة.
2. اختلاف ضمانات Memory وExternal Adapter عن PostgreSQL مقصود ومبين في تقرير التكافؤ؛ لا تستخدمها كبديل إنتاجي مكافئ من ناحية durability.
3. لا توجد موافقات موقعة خاصة بقرار إصدار P7-05 من مراجعي المحاسبة والأمن والمعمارية، ولا شهادة SOC أو امتثال تنظيمي. تسجل [مراجعة P4-08](../ard/ARD-P4-08.md) وملفات P5 اعتماد سيناريوهات/قدرات محددة؛ ذلك لا يعادل توقيع Go/No-Go لهذا الإصدار.
4. وحدات IFRS/IAS قدرات محددة النطاق وليست تطبيقًا كاملاً للمعايير. المتطلبات التالية موثقة صراحة خارج النطاق، وتحتاج تقييمًا منفصلًا قبل أي ادعاء أوسع:

| المعيار | أمثلة المتطلبات/المسائل خارج النطاق الموثق | المرجع |
| --- | --- | --- |
| IFRS 15 | المقابل المتغير وقيده، المكون التمويلي الهام، تعديلات/دمج/إنهاء العقود، تكاليف اقتناء العقد، وتحليل الأصيل/الوكيل؛ بعض أحكام الأداء والأدلة يقدمها النظام المضيف. | [ARD-P5-05](../ard/ARD-P5-05.md) |
| IFRS 16 | محاسبة المؤجر، إعفاءات قصير الأجل/منخفض القيمة، أحكام مدة الإيجار، الدفعات المتغيرة، تقييم التعديلات المنفصلة، انخفاض القيمة، الانتقال، والعملات الأجنبية. | [ARD-P5-06](../ard/ARD-P5-06.md) |

| IAS 21 | إعادة عرض الاقتصادات مفرطة التضخم وفق IAS 29، وإعادة تدوير فروق تصرف/التصرف الجزئي بعملية أجنبية. | [مصفوفة IAS 21](../accounting/ias21_compliance_matrix.md) |

5. Authentication والتفويض التجاري مسؤولية النظام المضيف وفق حدود المنتج؛ اجتياز اختبارات إعداد الخدمة لا يثبت تكامل هوية أو إعداد Gateway في نشر مستهدف.
2. نتائج GitHub الحالية غير حاسمة: آخر CI كان جاريًا وقت الاستعلام، وتشغيلات سابقة حديثة انتهت بالفشل. فحص حماية الفرع غير متاح عبر الواجهة المستخدمة.

## 6. شروط رفع No-Go

لا يُعاد تقييم القرار قبل إرفاق أدلة قابلة للمراجعة على الأقل لما يلي:

1. تنفيذ واستعادة Backup فعلية (أو PITR وفق النطاق التشغيلي)، ثم اجتياز فحوص المخطط والقيود والأرصدة وسلسلة التدقيق؛ وتحديث P7-03/ARD وفق النتيجة.
2. اكتمال كل CI Release Gates على التغييرات المرشحة، بما فيها race وsecurity/SBOM وservice integration، دون فشل أو skip غير مبرر.
3. إرفاق مراجعة محاسبية، وأمنية، ومعمارية بأسماء/أدوار وتواريخ ونطاق مراجعة وقرار؛ أو تسجيل المتطلبات غير المنطبقة بمبرر معتمد.
4. مراجعة إعدادات بيئة النشر المستهدفة، أسرارها، مصادقتها، عزل الشركة، الاستعادة، وحدود RPO/RTO قبل أي نشر.

## 7. قرار الإصدار

**NO-GO.** لا تُعلن النسخة الحالية جاهزة للإنتاج ولا تُنشر كإصدار مستقر بناءً على هذا التقرير. أسباب المنع هي: عدم إثبات Restore/PITR فعلي، وعدم اكتمال CI Release Gates للنسخة المقيمة، وغياب المراجعات والتصديقات المطلوبة. الدرجة 76.25% لا تلغي هذه الموانع.
