# ADR-0006 — شكل الإصدار وسياسة التخزين وToolchain

- **الحالة:** معتمد
- **التاريخ:** 2026-11-14
- **المالك:** مالك المشروع
- **يخدم:** `P0-04`, `P6-01`, `P7-06`

## القرارات

### 1. شكل الإصدار الأول: مكتبة Go قابلة للتضمين (Embedded SDK)

- المحرك يعمل داخل عملية النظام المضيف؛ لا يحتاج خدمة مستقلة.
- التعامل فقط عبر `pkg/sdk` و`pkg/api/v1` و`pkg/spi`.
- PostgreSQL وMemory موائمات اختيارية.
- HTTP/gRPC **ليست مطلوبة للإصدار الأول**؛ تبقى نقاط ربط اختيارية لاحقة دون تغيير النواة المحاسبية.
- أمثلة استهلاك خارجي وتوثيق إلزاميان.

**أثر على الخطة:** `P6-04` و`P6-05` يؤجَّلان خارج الإصدار الأول؛ `P6-01`..`P6-03` و`P6-06` تبقى لحماية أي نشر خدمي اختياري. `P7-01` يعتمد على SDK والموائمات لا على gRPC.

### 2. سياسة التخزين

- PostgreSQL هو الخيار الإنتاجي.
- Memory للاختبار والتطوير فقط، ويُختار صراحةً.
- لا اختيار تلقائي لـ Memory في الإنتاج؛ غياب `DATABASE_DSN` في Production خطأ.
- لا يجوز استخدام Memory كدليل Durability/RLS/Concurrency إنتاجي.

### 3. Toolchain

- `go 1.26.0` و`toolchain go1.26.3` يبقيان كما هما.
- لا تخفيض ولا تغيير اعتماديات لتجاوز قيود إصدار.
- بيئة التنفيذ الحالية: Go 1.26.3 (مطابق).

### 4. التجميد

- تُجمّد الميزات القطاعية وتوسيع المعايير وTransports الجديدة حتى إغلاق بوابات المنتج الأساسية.
- يسمح فقط بإصلاح عيب يمنع مهمة معتمدة أو يهدد سلامة البيانات.

## النتائج

- `cmd/accounting-service` يبقى كخيار نشر لكنه ليس شرطًا للإصدار.
- Release Notes توضح أن الإصدار مكتبة.
- Release Gate G7 يطبق على أي خدمة تُنشر، وعلى SDK عبر منع اختيار Memory الضمني في التهيئة الإنتاجية.
