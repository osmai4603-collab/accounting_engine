- **النوع:** مراجعة معمارية إلزامية (Phase 0 / `P0-T3`)
- **المرجع:** [`docs/phase-0-baseline-and-governance.md`](../phase-0-baseline-and-governance.md)

| الدور | الرمز | نطاق المراجعة |

## القرارات المعتمدة

| ADR | القرار | النتيجة |
| --- | --- | --- |
| ADR-0001 | `open → soft_closed → hard_closed` فقط، و`hard_closed` نهائية | معتمد |
| ADR-0002 | Fail-Closed في الإنتاج، و`StrictGovernance` إلزامي عند الإقلاع | معتمد |
| ADR-0003 | قفل صف الفترة وإعادة التحقق داخل معاملة الترحيل، وعقد `PostingStoragePort` | معتمد |
| ADR-0004 | بصمة الاعتماد تغطي كل حقل مؤثر محاسبياً | معتمد |
| ADR-0005 | تكافؤ تخزين بعقد مشترك + Expand/Contract للهجرات | معتمد |
| ADR-0006 | وحدات ERP مستقلة خلف منافذ ومرفقات ترحيل | معتمد |

## شروط معلقة (لا تمنع الاعتماد لكنها إلزامية قبل الإنتاج)

1. `ADR-0001`: يجب توفير أداة إدارية موثقة للتصحيح الاستثنائي قبل `P2-T4`.
2. `ADR-0002`: يجب إضافة فحص preflight للإقلاع واختبار رفض قبل `P1-T7`.
3. `ADR-0003`: يجب توثيق ترتيب الأقفال في `PostingStoragePort` واختباره تحت التزامن.
4. `ADR-0004`: يجب إضافة اختبار انعكاسي يمنع نسيان أي حقل جديد.
5. `ADR-0005`: يجب ترحيل الاستثناءات القديمة إلى خطة Contract قبل `P0-T8` النهائي.
6. `ADR-0006`: يجب اعتماد مخطط الحسابات الضابطة قبل بدء `P5-T2`.
