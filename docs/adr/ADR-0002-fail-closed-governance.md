# ADR-0002 — Fail-Closed Governance

- **الحالة:** معتمد
- **التاريخ:** 2026-11-12
- **المراجعة:** 2026-11-12
- **المالك:** `ARCH` + `SME` + `SRE`
- **الفجوات المرتبطة:** `GAP-GOV-03`, `GAP-GOV-04`
- **المهام المرتبطة:** `P1-T7`

## السياق

`ApprovalGate.IsApproved` يعيد `true` عندما تكون السياسة غير مهيأة (`policy == nil`) أو عندما لا تكون الشركة قد ضبطت حداً للموافقات، ما لم يكن `StrictGovernance=true`. هذا يعني أن الخطأ في الإعداد أو نسيان التهيئة في الإنتاج يتحول إلى **سماح صامت** بترحيل كل القيود دون اعتماد.

## القرار

1. **الوضع الافتراضي في الإنتاج مغلق (Fail-Closed).** غياب سياسة شركة صالحة يعني رفض الترحيل الذي يتطلب اعتماداً، مع رمز `APPROVAL_POLICY_UNCONFIGURED`.
2. `StrictGovernance` يصبح إلزامياً عند الإقلاع في بيئة الإنتاج. لا يكفي أن يكون حقلاً اختيارياً في `Config`.
3. يتحقق مسار الإقلاع (`New`/`Serve`) من:
   - وجود سياسة افتراضية أو سياسة لكل شركة نشطة،
   - صلاحية الحدود (غير سالبة، بعملة الشركة الوظيفية)،
   - وجود مسار اعتماد قابل للاستدعاء.
   وإلا يفشل الإقلاع برسالة واضحة.
4. لا يوجد تجاوز لكل طلب. التجاوز الوحيد المسموح هو `ALLOW_UNCONFIGURED_APPROVALS=true` في بيئة تطوير صريحة، ويُسجَّل تحذيراً عالي الخطورة عند كل إقلاع.
5. أي قيد يتجاوز حد الموافقة ولا يملك اعتماداً مكتملاً يُرفض قبل أي كتابة، لا بعدها.
6. تُسجَّل كل محاولة رفض بـ`company_id`, `entry_id`, `period_id`, `policy_version`, `trace_id`.

## البدائل المرفوضة

| البديل | سبب الرفض |
| --- | --- |
| الإبقاء على Fail-Open مع تحذير في السجل | التحذير لا يمنع ترحيلاً غير معتمد؛ الضرر المالي يقع قبل قراءة السجل |
| جعل `StrictGovernance` اختيارياً لكل نشر | يعيد المشكلة نفسها: خطأ إعداد واحد يفتح الباب |
| فرض سياسة عامة واحدة على كل الشركات | لا يراعي اختلاف حدود الشركات واختلاف الصلاحيات |
| رفض كل القيود عند غياب السياسة بلا رمز خطأ | يجعل التشخيص صعباً ويخلط بين خطأ الإعداد وخطأ المدخل |

## النتائج

- خطأ الإعداد يظهر عند الإقلاع لا عند أول ترحيل مالي.
- تحتاج بيئات الاختبار إلى سياسة صريحة أو علم تطوير واضح.
- ترتفع الحاجة إلى اختبارات إقلاع (startup) واختبارات رفض قبل الكتابة.

## المخاطر

| المخاطرة | التخفيف |
| --- | --- |
| تعطل نشر قديم لعدم وجود سياسة | دليل ترحيل إعداد + فحص preflight + فترة انتقال |
| زيادة الاحتكاك على الفرق | سياسات افتراضية موثقة لكل بيئة |
| تجاوز العلم التطويري في الإنتاج | ربط العلم ببيئة صريحة ورفضه عند `APP_ENV=production` |
