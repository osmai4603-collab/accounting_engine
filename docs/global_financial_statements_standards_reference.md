# الدليل المرجعي الموسوعي الشامل للقوائم المالية والمعايير العالمية

## Global Financial Statements & Reporting Standards Reference Guide

### استناداً إلى معايير IFRS / IAS / IFRS 18، US GAAP، IPSAS، AAOIFI، و ISSB

---

**تاريخ الإصدار:** نوفمبر 2026  
**الإصدار:** 1.0 (Comprehensive Authority Edition)  
**التصنيف:** معايير المحاسبة المالية، إعداد التقارير المالية الدولية، ونمذجة الأنظمة البرمجية المحاسبية  
**الجهات المعيارية المعتمدة:**

1. **مجلس معايير المحاسبة الدولية (IASB) / مؤسسة المعايير الدولية للتقرير المالي (IFRS Foundation):** معايير التقرير المالي الدولية (IFRS Standards) ومعايير المحاسبة الدولية (IAS Standards) والمعيار الثوري الجديد IFRS 18.
2. **مجلس معايير المحاسبة المالية الأمريكي (FASB):** تدوين معايير المحاسبة الأمريكية (US GAAP / Accounting Standards Codification - ASC).
3. **مجلس معايير المحاسبة الدولية للقطاع العام (IPSASB):** معايير المحاسبة للقطاع العام والحكومي (IPSAS).
4. **هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية (AAOIFI):** معايير المحاسبة المالية الإسلامية (FAS).
5. **مجلس معايير الاستدامة الدولية (ISSB):** معايير الإفصاحات المالية المرتبطة بالاستدامة والمناخ (IFRS S1 و IFRS S2).
6. **المنظمة الدولية للمعايير (ISO):** معيار ISO 4217 (العملات والوحدات الكسرية) ومعيار ISO 20022 (الرسائل المالية القياسية).
7. **منظمة معايير تقارير الأعمال القابلة للتوسيع (XBRL International):** تاكسونومي IFRS و US GAAP الرقمي (Digital Reporting Taxonomies).

## 1. الإطار المفاهيمي العام للتقارير المالية ذات الأغراض العامة

### 1.1 هدف التقارير المالية (Objective of General Purpose Financial Reporting)

وفقاً للإطار المفاهيمي لمؤسسة المعايير الدولية (IASB Conceptual Framework) والإطار الصادر عن مجلس معايير المحاسبة المالية الأمريكي (FASB Concepts Statement No. 8)، يتمثل الهدف الجوهري للتقارير المالية ذات الأغراض العامة في:
> **"توفير معلومات مالية حول المنشأة المعدة للتقرير تكون مفيدة للمستثمرين الحاليين والمرتقبين، والمقرضين، والدائنين الآخرين في اتخاذ القرارات المتعلقة بتوفير الموارد للمنشأة."**

تلك القرارات تتضمن:

- شراء أو بيع أو حيازة أدوات حقوق الملكية وأدوات الدين.
- تقديم القروض أو الأشكال الأخرى من الائتمان أو تسويتها.
- ممارسة الحقوق في التصويت أو التأثير على تصرفات الإدارة التي تؤثر على استخدام الموارد الاقتصادية للمنشأة (المساءلة والإشراف - Stewardship).

---

### 1.2 الخصائص النوعية للمعلومات المالية المفيدة (Qualitative Characteristics)

لضمان موثوقية وفائدة القوائم المالية في النظم المحاسبية الدولية، يجب الالتزام بنوعين من الخصائص:

#### أولاً: الخصائص النوعية الأساسية (Fundamental Qualitative Characteristics)

1. **الملاءمة (Relevance):** قدرة المعلومة على إحداث فرق في القرارات الاقتصادية، وتتضمن:
   - **القيمة التنبؤية (Predictive Value):** المساعدة في استشراف النتائج المستقبلية.
   - **القيمة التأكيدية (Confirmatory Value):** التحقق من التقييمات السابقة أو تصحيحها.
   - **الأهمية النسبية (Materiality):** اعتبار المعلومة جوهرية إذا كان حذفها أو تحريفها أو حجبها قد يؤثر منطقياً على قرارات المستخدمين.
2. **التمثيل الصادق (Faithful Representation):** أن تمثل المعلومات جوهر الظواهر الاقتصادية بدلاً من مجرد شكلها القانوني (Substance over Form)، وتتطلب:
   - **الاكتمال (Completeness):** تضمين كافة المعلومات والشروحات الضرورية.
   - **الحياد (Neutrality):** خلو التقرير من التحيز أو التوجيه الانتقائي.
   - **الخلو من الأخطاء الجوهرية (Free from Material Error).**

#### ثانياً: الخصائص النوعية المعززة (Enhancing Qualitative Characteristics)

1. **القابلية للمقارنة (Comparability):** التوافق عبر الفترات الزمنية للمنشأة، ومع المنشآت النظيرة.
2. **القابلية للتحقق (Verifiability):** إمكانية وصول مراقبين مستقلين ومطلعين إلى نفس النتيجة (مسار التدقيق Audit Trail).
3. **التوقيت المناسب (Timeliness):** توفير المعلومات لمتخذي القرار في الوقت المناسب للتأثير على خياراتهم.
4. **القابلية للفهم (Understandability):** تصنيف وتبويب وتوصيل المعلومات بوضوح وإيجاز.

### 1.3 العناصر البنيوية للقوائم المالية (Elements of Financial Statements)

تُبنى جميع القوائم المالية المعيارية على خمسة عناصر محاسبية رئيسية محددة بدقة:

```text
                          ┌──────────────────────────┐
                          │ العناصر المحاسبية الدولية │
                          └─────────────┬────────────┘
                ┌───────────────────────┴───────────────────────┐
                ▼                                               ▼
      ┌──────────────────┐                            ┌──────────────────┐
      │  المركز المالي   │                            │  الأداء المالي   │
      │ Financial Position│                            │ Financial Performance│
      └─────────┬────────┘                            └─────────┬────────┘
     ┌──────────┼──────────┐                         ┌──────────┴──────────┐
     ▼          ▼          ▼                         ▼                     ▼
 ┌───────┐ ┌─────────┐ ┌──────┐                  ┌───────┐             ┌─────────┐
 │الأصول │ │الالتزامات│ │الملكية│                  │الإيراد │             │ المصروف │
 │Assets │ │Liabilities│ │Equity│                  │Income │             │ Expense │
 └───────┘ └─────────┘ └──────┘                  └───────┘             └─────────┘
```

1. **الأصل (Asset):** مورد اقتصادي حالي تسيطر عليه المنشأة نتيجة لأحداث سابقة، والمورد الاقتصادي هو حق لديه القدرة على إنتاج منافع اقتصادية.
2. **الالتزام (Liability):** واجب حالي على المنشأة لتحويل مورد اقتصادي نتيجة لأحداث سابقة، ولا تملك المنشأة قدرة عملية على تجنبه.
3. **حقوق الملكية (Equity):** الحصة المتبقية في أصول المنشأة بعد خصم جميع التزاماتها ($Equity = Assets - Liabilities$).
4. **الدخل / الإيراد (Income / Revenue):** الزيادات في الأصول أو النقص في الالتزامات التي ينتج عنها زيادات في حقوق الملكية، بخلاف تلك المتعلقة بمساهمات حاملي حقوق الملكية.
5. **المصروفات (Expenses):** الانخفاضات في الأصول أو الزيادات في الالتزامات التي ينتج عنها انخفاض في حقوق الملكية، بخلاف تلك المتعلقة بالتوزيعات على حاملي حقوق الملكية.

### 1.4 أسس القياس المحاسبي المعتمدة دولياً (Measurement Bases)

تحدد المعايير الدولية خمسة أسس رئيسية لقياس العناصر في القوائم المالية:

| أساس القياس (Measurement Basis) | التعريف المعياري الدقيق | المعايير المرتبطة | حالات الاستخدام الرئيسية |
| :--- | :--- | :--- | :--- |
| **التكلفة التاريخية (Historical Cost)** | المقابل النقدي المدفوع أو القيمة العادلة للعوض المقدم لاقتناء الأصل وقت المعاملة، مخصوماً منه الاستهلاك أو التدني. | IAS 16, IAS 38, ASC 360 | الأصول الثابتة، الأصول غير الملموسة، الالتزامات غير المالية. |
| **القيمة العادلة (Fair Value)** | السعر الذي سيتم استلامه لبيع أصل أو دفعه لنقل التزام في معاملة منظمة بين مشاركين في السوق في تاريخ القياس (سعر الخروج Exit Price). | IFRS 13, ASC 820 | الأدوات المالية، العقارات الاستثمارية، تقييمات الاندماج والاستحواذ. |
| **القيمة الحالية / القيمة قيد الاستخدام (Present Value / Value in Use)** | القيمة الحالية للتدفقات النقدية المستقبلية المقدرة المتوقع الحصول عليها من الأصل أو سداد الالتزام مخصومة بمعدل خصم ملائم. | IAS 36, IFRS 16, ASC 842 | اختبارات تدني الأصول، التزامات عقود الإيجار، مخصصات التقاعد. |
| **صافي القيمة القابلة للتحقق (Net Realisable Value - NRV)** | سعر البيع التقديري في السياق العادي للأعمال مخصوماً منه التكاليف التقديرية للإتمام وتكاليف البيع الضرورية. | IAS 2, ASC 330 | قياس المخزون (الأقل بين التكلفة وصافي القيمة القابلة للتحقق). |
| **التكلفة المطفأة (Amortised Cost)** | المبلغ الذي يقاس به الأصل أو الالتزام المالي عند الاعتراف المبدئي ناقصاً أقساط الأصل المسددة، زائداً أو ناقصاً الإطفاء المتراكم باستخدام سعر الفائدة الفعلي (EIR). | IFRS 9, ASC 310 / ASC 320 | الذمم المدينة التجارية، السندات، القروض، التزامات الاقتراض البنكية. |

## 2. التصنيف والتبويب الشامل لجميع أنواع القوائم المالية في العالم

تنقسم القوائم المالية وفقاً للتشريعات الدولية إلى عدة تصنيفات رئيسية وفقاً لطبيعة المنشأة، الغرض من التقرير، الدورة الزمنية، والقطاع المؤسسي:

### 2.1 المجموعة الكاملة للقوائم المالية للأغراض العامة (IAS 1 & IFRS 18 / ASC 205)

تتألف المجموعة السنوية الكاملة للقوائم المالية للمنشأة الهادفة للربح من:

1. **قائمة المركز المالي (Statement of Financial Position / Balance Sheet):** في نهاية الفترة.
2. **قائمة الأرباح أو الخسائر والدخل الشامل الآخر (Statement of Profit or Loss and Other Comprehensive Income):** عن الفترة.
3. **قائمة التغيرات في حقوق الملكية (Statement of Changes in Equity):** عن الفترة.
4. **قائمة التدفقات النقدية (Statement of Cash Flows):** عن الفترة.
5. **الإيضاحات المتممة (Notes to the Financial Statements):** وتشمل ملخصاً للسياسات المحاسبية الجوهرية والمعلومات التفسيرية الأخرى.
6. **قائمة مركز مالي في بداية أقرب فترة مقارنة:** عند تطبيق سياسة محاسبية بأثر رجعي، أو إعادة تبويب، أو تعديل أخطاء جوهرية وفق IAS 8 / ASC 250.

---

### 2.2 القوائم المالية الموحدة مقابل المستقلة والمجمعة (Consolidated, Separate & Combined)

#### 1. القوائم المالية الموحدة (Consolidated Financial Statements - IFRS 10 / ASC 810)

- **النطاق:** تصدرها المنشأة الأم (Parent Entity) التي تسيطر على شركة تابعة واحدة أو أكثر (Subsidiaries).
- **مفهوم السيطرة (Control Criteria):** تتوافر السيطرة إذا وفقط إذا توافرت للمستثمر ثلاثة أركان:
  1. السلطة على المنشأة المستثمر فيها (Power over investee).
  2. التعرض لحقوق في عوائد متغيرة أو الحق فيها من خلال ارتباطه بالمنشأة (Exposure/rights to variable returns).
  3. القدرة على استخدام سلطته للتأثير على مبلغ عوائد المستثمر (Ability to use power).
- **آلية التوحيد:** تجميع الأصول والالتزامات وحقوق الملكية والإيرادات والمصروفات بالكامل سطر بسطر (Line-by-line)، مع **إلغاء تام** لجميع المعاملات البينية (Intercompany eliminations):
  - إلغاء القيمة الدفترية لاستثمار الشركة الأم مقابل حصتها في حقوق ملكية التابعة.
  - إثبات الشهرة (Goodwill) الناتجة عن تجميع الأعمال (IFRS 3 / ASC 805).
  - إثبات حقوق الأقلية أو الحصص غير المسيطرة (Non-Controlling Interests - NCI) بشكل مستقل داخل حقوق الملكية.
  - إلغاء الأرصدة البينية (الذمم الدائنة والمدينة بين الشركات الشقيقة).
  - إلغاء الأرباح أو الخسائر غير المحققة الناتجة عن مبيعات المخزون أو الأصول الرأسمالية البينية.

#### 2. القوائم المالية المستقلة (Separate Financial Statements - IAS 27 / ASC 810-10)

- هي القوائم التي تقدمها المنشأة الأم بمفردها ككيان قانوني مستقل.
- تُمكّن المنشأة من قياس استثماراتها في الشركات التابعة والزميلة والمشاريع المشتركة بأحد الخيارات:
  - بالتكلفة (Cost).
  - وفقاً لمعيار IFRS 9 (بالقيمة العادلة).
  - باستخدام طريقة حقوق الملكية (Equity Method) كما هي موصوفة في معيار IAS 28.

#### 3. القوائم المالية المجمعة (Combined Financial Statements)

- تُعد لمجموعة من الكيانات الخاضعة لسيطرة مشتركة (Common Control) دون وجود علاقة شركة أم بشركاتها التابعة (مثل منشآت يملكها نفس المساهم الفرد أو نفس العائلة الاستثمارية).

---

### 2.3 القوائم المالية المرحلية / الأولية (Interim Financial Reporting - IAS 34 / ASC 270)

- تصدر عن فترات أقل من سنة مالية كاملة (ربع سنوية Quarterly، أو نصف سنوية Semi-Annual).
- تتطلب عرضاً مكثفاً (Condensed Financial Statements) يركز على الأحداث والمعاملات الجديدة والمؤثرة، وتشمل:
  - قائمة مركز مالي مكثفة كما في نهاية الفترة المرحلية، ومقارنتها بنهاية السنة المالية السابقة مباشرة.
  - قوائم دخل وتدفقات نقدية وتغيرات ملكية للفترة المرحلية الحالية، والتراكمية حتى تاريخه (Year-to-Date)، مقارنة بنفس الفترات من السنة السابقة.
- التقديرات المحاسبية: تطبق نفس السياسات المحاسبية المعتمدة في القوائم السنوية مع الاعتماد الأكبر على التقديرات (مثل احتساب مخصص ضريبة الدخل السنوية المتوقعة وتوزيعها على الفترات المرحلية).

---

### 2.4 تقارير القطاعات التشغيلية (Operating Segments - IFRS 8 / ASC 280)

- إلزامية للشركات المدرجة في الأسواق المالية (Publicly Traded Entities).
- تعتمد على **"مدخل الإدارة" (Management Approach)**: أي كيفية تقسيم الأعمال ومراقبة الأداء بواسطة متخذ القرار التشغيلي الرئيسي (Chief Operating Decision Maker - CODM).
- معايير التقرير الكمية (10% Thresholds): يجب الإفصاح المستقل عن أي قطاع يحقق 10% أو أكثر من:
  - إجمالي الإيرادات (المحلية والبيعية للقطاعات الأخرى).
  - أو القيمة المطلقة للربح أو الخسارة التشغيلية.
  - أو إجمالي أصول القطاعات.
- قاعدة التغطية الكلية (75% Rule): يجب أن تشكل إيرادات القطاعات التشغيلية المفصح عنها خارجياً ما لا يقل عن 75% من إجمالي الإيرادات الموحدة للمنشأة.

---

### 2.5 القوائم المالية على أساس التصفية (Liquidation Basis of Accounting - ASC 205-30)

- عندما تصبح فرضية الاستمرارية (Going Concern) غير سارية وتصبح التصفية وشيكة:
  - يُحظر استخدام معايير المحاسبة العادية (IFRS / US GAAP القائمة على الاستمرارية).
  - تُقاس الأصول بالمبالغ النقدية التقديرية المتوقع تحصيلها بعد خصم تكاليف التخلص منها (Estimated Net Realisable Value).
  - تُثبت التزامات إضافية ناشئة عن إنهاء العقود، ومكافآت نهاية الخدمة الإضافية، ومصاريف التصفية المستقبلية المقدرة.
  - يتم استبدال قائمة المركز المالي بقائمة: **قائمة صافي الأصول قيد التصفية (Statement of Net Assets in Liquidation)** وقائمة **التغيرات في صافي الأصول قيد التصفية (Statement of Changes in Net Assets in Liquidation)**.

---

### 2.6 معايير المنشآت الصغيرة والمتوسطة (IFRS for SMEs)

- إطار مبسط ومستقل ومصمم خصيصاً للشركات التي لا تخضع للمساءلة العامة (Non-publicly accountable).
- تبسيطات جوهرية مقارنة بـ IFRS الكامل:
  - عدم الاعتراف بـ IFRS 16 المعقد لعقود الإيجار (الاحتفاظ بنموذج الإيجار التشغيلي والرأسمالي البسيط).
  - استهلاك الشهرة على عمر إنتاجي مقدر (عادة 10 سنوات إذا تعذر التقدير)، بدلاً من اختبار التدني السنوي المعقد.
  - رسملة تكاليف التطوير ممنوعة، وتُحمّل جميع تكاليف البحث والتطوير على المصروفات فوراً.
  - إعفاءات واسعة من الإفصاحات المفصلة وحسابات الأدوات المالية المشتقة المعقدة.

---

### 2.7 القوائم المالية للقطاع العام والحكومي (IPSAS Standards)

يحدد معيار المحاسبة الدولي للقطاع العام (IPSAS 1) قوائم مالية ذات بنية مميزة للمؤسسات الحكومية والبلديات:

1. **قائمة المركز المالي (Statement of Financial Position):** تُعرض فيها الالتزامات والأصول و"صافي الأصول / حقوق الملكية" (Net Assets / Equity).
2. **قائمة الأداء المالي (Statement of Financial Performance):** تعادل قائمة الدخل، وتقيس الفائض أو العجز المالي (Surplus or Deficit).
3. **قائمة التغيرات في صافي الأصول / حقوق الملكية (Statement of Changes in Net Assets / Equity).**
4. **قائمة التدفقات النقدية (Cash Flow Statement - IPSAS 2).**
5. **قائمة مقارنة الموازنة التقديرية بالمبالغ الفعلية (Comparison of Budget and Actual Amounts - IPSAS 24):** إلزامية لأي جهة تنشر موازنتها علناً، وتفصل الانحرافات بين الاعتمادات المعتمدة في الموازنة والصرف الفعلي.
6. **الإيضاحات والسياسات المحاسبية الحكومية.**

---

### 2.8 القوائم المالية للمؤسسات المالية والمصارف الإسلامية (AAOIFI FAS 1)

وفقاً للمعيار المحاسبي المالي رقم (1) الصادر عن هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية:

1. **قائمة المركز المالي (Statement of Financial Position):** تتضمن تبويباً فريداً لـ **"حقوق أصحاب حسابات الاستثمار غير المقيدة" (Unrestricted Investment Account Holders - URIA)**، وهي فئة تقع بين الالتزامات وحقوق الملكية وتسمى "شبه حقوق الملكية" (Quasi-Equity).
2. **قائمة الدخل (Income Statement):** توضح إيرادات الاستثمارات المشتركة، مخصوماً منها حصة أصحاب حسابات الاستثمار في العوائد، مضافاً إليها إيرادات البنك كوكيل أو مضارب.
3. **قائمة التدفقات النقدية (Statement of Cash Flows).**
4. **قائمة التغيرات في حقوق الملاك (Statement of Changes in Owners' Equity).**
5. **قائمة التغيرات في الاستثمارات المقيدة (Statement of Changes in Restricted Investments):** خارج الميزانية (Off-Balance Sheet) لأن البنك يديرها بصفته مديراً للاستثمار أو وكيلاً دون تحمل مخاطر رأس المال.
6. **قائمة مصادر واستخدامات أموال صندوق الزكاة والصدقات (Statement of Sources and Uses of Zakah and Charity Fund):** تبرز الالتزام الشرعي في جباية وتوزيع الزكاة.
7. **قائمة مصادر واستخدامات أموال صندوق القرض الحسن (Statement of Sources and Uses of Funds in Qard Fund):** تتبع القروض التنموية والخيرية الخالية من أي فوائد.

### 2.9 تقارير الإفصاحات المالية المرتبطة بالاستدامة والمناخ (IFRS S1 & IFRS S2 - ISSB)

أطلق مجلس معايير الاستدامة الدولية (ISSB) التابع لمؤسسة IFRS معيارين تأسيسيين أصبحا ملزمين في العديد من الأسواق المالية:

1. **معيار IFRS S1 (المتطلبات العامة للإفصاح عن المعلومات المالية المتعلقة بالاستدامة):** يلزم المنشأة بالإفصاح عن المخاطر والفرص المتعلقة بالاستدامة عبر أربعة أركان أساسية متوافقة مع TCFD: (الحوكمة Governance، الاستراتيجية Strategy، إدارة المخاطر Risk Management، والمقاييس والأهداف Metrics & Targets).
2. **معيار IFRS S2 (الإفصاحات المتعلقة بالمناخ):** تفصيل انبعاثات غازات الاحتباس الحراري (Scope 1 المباشرة، Scope 2 غير المباشرة من الطاقة المشتراة، و Scope 3 عبر سلسلة القيمة بالكامل)، وأثر التغير المناخي المادي والانتقالي على التدفقات النقدية المستقبلية والتكاليف الرأسمالية للمنشأة.

### 3.1 قائمة المركز المالي (Statement of Financial Position / Balance Sheet)

*المعايير المرجعية: IAS 1 / IFRS 18 / US GAAP ASC 210 / IPSAS 1*

#### الهدف المحاسبي

بيان الموقف المالي للمنشأة في **لحظة زمنية محددة (Point in Time)**، موضحاً الموارد الاقتصادية التي تسيطر عليها (الأصول)، والالتزامات المالية الواجبة عليها، ورأس المال المتبقي للملاك.

#### المعادلة الرياضية الجوهرية

$$\text{Total Assets} = \text{Total Liabilities} + \text{Total Equity}$$

$$\text{Current Assets} + \text{Non-Current Assets} = \text{Current Liabilities} + \text{Non-Current Liabilities} + (\text{Share Capital} + \text{Reserves} + \text{Retained Earnings} + \text{AOCI})$$

#### قواعد العرض والتبويب

- **تصنيف متداول / غير متداول (Current / Non-Current Presentation):** هو الأساس الإلزامي بموجب IAS 1 إلا إذا كان العرض القائم على **درجة السيولة (Order of Liquidity)** يوفر معلومات أكثر موثوقية وملاءمة (كما في البنوك والمؤسسات المالية).
- **تعريف البند المتداول (Current Item):**
  - يتوقع تحققه أو استهلاكه أو سداده خلال دورة التشغيل العادية للمنشأة (Operating Cycle).
  - يُحتفظ به أساساً لغرض التداول (Trading).
  - يتوقع تحققه أو يجب تسويته خلال اثني عشر شهراً بعد تاريخ التقرير.
  - نقد أو معادل نقد ما لم يكن مقيداً من الاستبدال أو الاستخدام لسداد التزام لمدة لا تقل عن 12 شهراً.

#### البنود الإلزامية في صلب قائمة المركز المالي (Mandatory Face Items - IAS 1.54)

1. الممتلكات والمصانع والمعدات (Property, Plant and Equipment - PPE - IAS 16).
2. العقارات الاستثمارية (Investment Property - IAS 40).
3. الأصول غير الملموسة والشهرة (Intangible Assets & Goodwill - IAS 38 / IFRS 3).
4. الأصول المالية (Financial Assets - باستثناء المبالغ المذكورة في بنود أخرى - IFRS 9).
5. الاستثمارات المحاسب عنها بطريقة حقوق الملكية (Investments in Associates & Joint Ventures - IAS 28).
6. الأصول الحيوية (Biological Assets - IAS 41).
7. المخزون (Inventories - IAS 2).
8. الذمم المدينة التجارية والمدينون الآخرون (Trade and other receivables).
9. النقد وما في حكمه (Cash and cash equivalents - IAS 7).
10. إجمالي الأصول المصنفة كمحتفظ بها للبيع بموجب IFRS 5.
11. الذمم الدائنة التجارية والدائنون الآخرون (Trade and other payables).
12. المخصصات (Provisions - IAS 37).
13. الالتزامات المالية (Financial Liabilities - IFRS 9).
14. التزامات وأصول الضرائب الحالية والمؤجلة (Current & Deferred Tax Liabilities/Assets - IAS 12).
15. الالتزامات المدرجة ضمن مجموعات التخلص المصنفة كمحتفظ بها للبيع (IFRS 5).
16. الحصص غير المسيطرة (Non-controlling interests - NCI)، وتُعرض ضمن حقوق الملكية بشكل منفصل.
17. رأس المال المصدر والاحتياطيات العائدة لمساهمي الشركة الأم.

### 3.2 قائمة الأرباح أو الخسائر والدخل الشامل الآخر (Statement of Profit or Loss and OCI)

*المعايير المرجعية: IAS 1 / المعيار الجديد IFRS 18 (2024/2027) / US GAAP ASC 220*

#### الهدف المحاسبي

قياس الأداء المالي والربحي للمنشأة خلال **فترة زمنية (Period of Time)**، ويعكس توليد القيمة الاقتصادية من الأنشطة التشغيلية والاستثمارية والتمويلية، بالإضافة إلى المكاسب والخسائر غير المحققة المقيدة في حقوق الملكية.

#### طرق العرض المعتمدة

1. **قائمة واحدة مدمجة (Single Statement of Comprehensive Income):** تعرض الأرباح أو الخسائر أولاً، تليها مباشرة بنود الدخل الشامل الآخر مع وصول إلى المجموع الكلي للدخل الشامل.
2. **قائمتان منفصلتان (Two-Statement Approach):**
   - الأولى: قائمة الأرباح أو الخسائر المنفصلة (Separate Income Statement).
   - الثانية: قائمة الدخل الشامل (Statement of Comprehensive Income) تبدأ بصافي ربح أو خسارة الفترة وتضيف بنود OCI.

#### التحول التاريخي الثوري: معيار IFRS 18 (بديل IAS 1 الفعّال بدءاً من 2027)

يُنهي IFRS 18 العشوائية في حساب "الربح التشغيلي" ويُلزم الشركات عالمياً بتبويب قائمة الدخل في **خمس فئات حصرية موحدة ومحددة**:

1. **فئة التشغيل (Operating Category):** وهي الفئة المتبقية (Residual) التي تشمل كافة الإيرادات والمصروفات الناتجة عن الأنشطة التشغيلية والجوهرية للمنشأة.
2. **فئة الاستثمار (Investing Category):** وتشمل عوائد الأصول التي تولد دخلاً فردياً ومستقلاً عن أصول المنشأة الأخرى (مثل عوائد الأسهم، السندات، العقارات الاستثمارية، والنقد المعادل).
3. **فئة التمويل (Financing Category):** التكاليف والفوائد الناتجة عن الالتزامات التي تهدف لجمع التمويل (الديون البنكية، السندات، والتزامات الإيجار IFRS 16)، وتكاليف الفوائد على التزامات المعاشات التقاعدية.
4. **فئة ضرائب الدخل (Income Taxes Category):** وتخضع لمعيار IAS 12.
5. **فئة العمليات غير المستمرة (Discontinued Operations Category):** وتخضع لمعيار IFRS 5.

#### الإجماليات الفرعية الإلزامية بموجب IFRS 18 (Mandatory Subtotals)

- **الربح أو الخسارة التشغيلية (Operating Profit or Loss):** يعرض بعد فئة التشغيل مباشرة، ويمثل لأول مرة مؤشراً محاسبياً موحداً عالمياً.
- **الربح أو الخسارة قبل التمويل وضرائب الدخل (Profit or Loss before Financing and Income Taxes).**

#### بنود الدخل الشامل الآخر (Other Comprehensive Income - OCI)

تُقسم بنود OCI وجوباً بموجب IAS 1 و IFRS 18 إلى مجموعتين بناءً على قابليتها لإعادة التدوير:

### 3.3 قائمة التغيرات في حقوق الملكية (Statement of Changes in Equity)

*المعايير المرجعية: IAS 1.106 / US GAAP ASC 505 / IPSAS 1*

#### الهدف المحاسبي

تسوية حركة حسابات حقوق الملكية بين بداية ونهاية الفترة المالية، مع إبراز المعاملات الرأسمالية مع الملاك بصفتهم تلك (Capital transactions with owners) مفصولة عن الأداء التشغيلي الشامل (Comprehensive Income).

#### المتطلبات الإلزامية بموجب معيار IAS 1

1. إجمالي الدخل الشامل للفترة، مبيناً المبالغ العائدة للمساهمين في الشركة الأم والحصص غير المسيطرة.
2. لكل بند من بنود حقوق الملكية: آثار التطبيق بأثر رجعي أو إعادة الإثبات بأثر رجعي بموجب معيار IAS 8.

### 3.4 قائمة التدفقات النقدية (Statement of Cash Flows)

*المعايير المرجعية: IAS 7 / US GAAP ASC 230 / IPSAS 2*

#### الهدف المحاسبي

توضيح قدرة المنشأة على توليد النقد وما في حكمه، واحتياجات المنشأة لاستخدام تلك التدفقات النقدية، وتقييم السيولة والمرونة المالية، وإلغاء أثر مبدأ الاستحقاق لتقديم صورة نقدية خالصة.

#### تعريف النقد وما في حكمه (Cash and Cash Equivalents)

- **النقدية (Cash):** النقد في الصندوق والودائع تحت الطلب.
- **معادلات النقدية (Cash Equivalents):** استثمارات مالية قصيرة الأجل عالية السيولة وقابلة للتحويل الفوري إلى مبالغ نقدية محددة ومعروفة، مع تعرض ضئيل لمخاطر تغير القيمة (عادة لا يتجاوز أجل استحقاقها **ثلاثة أشهر** من تاريخ الاقتناء).

#### الأنشطة الثلاثة الرئيسية

1. **الأنشطة التشغيلية (Operating Activities):** الأنشطة الرئيسية المنتجة للإيراد للمنشأة، وتعتبر المؤشر الأساسي على قدرة العمليات على سداد القروض والحفاظ على الطاقة الإنتاجية ودفع التوزيعات دون اللجوء للتمويل الخارجي.
2. **الأنشطة الاستثمارية (Investing Activities):** اقتناء واستبعاد الأصول طويلة الأجل والاستثمارات الأخرى التي لا تدخل ضمن معادلات النقدية (تمثل مدى النفقات التي تمت على موارد هدفها توليد دخل وتدفقات نقدية مستقبلية).
3. **الأنشطة التمويلية (Financing Activities):** الأنشطة التي تؤدي إلى تغيرات في حجم وتركيبة حقوق الملكية وحركات اقتراض المنشأة.

#### المقارنة المنهجية: الطريقة المباشرة مقابل الطريقة غير المباشرة

- **الطريقة المباشرة (Direct Method):** الإفصاح عن الفئات الرئيسية لإجمالي المقبوضات النقدية وإجمالي المدفوعات النقدية التشغيلية (مقبوضات من العملاء، مدفوعات للموردين، مدفوعات للموظفين). **يوصي بها معيار IAS 7 بشدة** لأنها توفر معلومات أكثر نفعاً لا تتيحها الطريقة غير المباشرة.
- **الطريقة غير المباشرة (Indirect Method):** تبدأ بصافي الربح أو الخسارة، ثم تعديله بـ:
  1. أثر المعاملات غير النقدية (الاستهلاك، الإطفاء، مخصصات التدني، الأرباح/الخسائر غير المحققة لتقييم العملات).
  2. التغيرات في رأس المال العامل التشغيلي (التغير في المخزون، الذمم المدينة، الذمم الدائنة).
  3. كافة البنود الأخرى ذات الطبيعة الاستثمارية أو التمويلية (مثل أرباح أو خسائر بيع الأصول الثابتة، وفوائد الاقتراض).

#### المعاملات غير النقدية الاستثمارية والتمويلية (Non-Cash Transactions)

يحظر معيار IAS 7 إدراج المعاملات غير النقدية في صلب قائمة التدفقات النقدية، ويوجب الإفصاح عنها في الإيضاحات، مثل:

- اقتناء أصول عبر إصدار أسهم أو عبر عقود إيجار تمويلي (IFRS 16).
- تحويل الديون أو السندات إلى أسهم حقوق ملكية.
- الاستحواذ على شركات عبر مبادلة أسهم (Share-for-share exchange).

### 3.5 الإيضاحات المتممة للقوائم المالية (Notes to the Financial Statements)

*المعايير المرجعية: IAS 1.112 - 138 / US GAAP ASC 235*

الإيضاحات جزء لا يتجزأ من القوائم المالية، وتقرأ معها كوحدة واحدة. يجب أن تُعرض بطريقة منظمة ومنسقة، وأن يربط كل بند في صلب القوائم بالإيضاح الخاص به.

#### البنية القياسية للإيضاحات المتممة

1. **معلومات المنشأة والنشاط الرئيسي (Corporate Information):** الشكل القانوني، بلد التأسيس، عنوان المقر المسجل، ووصف طبيعة العمليات والأنشطة الرئيسية.
2. **بيان الالتزام بالمعايير (Statement of Compliance):** إقرار صريح وغير متحفظ بالامتثال لـ IFRS أو US GAAP أو المعايير المحلية المعتمدة.
3. **أسس الإعداد والقياس (Basis of Preparation & Measurement):** العملة الوظيفية (Functional Currency) وعملة العرض (Presentation Currency)، ومستوى التقريب (الآلاف أو الملايين).
4. **ملخص السياسات المحاسبية الجوهرية (Material Accounting Policies - IAS 1 المعدل):**
   - سياسة الاعتراف بالإيراد وفق معيار IFRS 15 (الخطوات الخمس).
   - أسس تبويب وقياس الأدوات المالية وفق IFRS 9 ونموذج الخسائر الائتمانية (ECL).
   - سياسات الإهلاك وتحديد الأعمار الإنتاجية للأصول الثابتة (IAS 16).
   - المعالجة المحاسبية لعقود الإيجار ونسب الخصم المعتمدة (IFRS 16).
5. **التقديرات والأحكام المحاسبية الهامة (Significant Accounting Judgments & Estimates):**
   - افتراضات اختبارات هبوط القيمة والشهرة (Discount rates, Terminal growth rates).
   - تقدير الأعمار الإنتاجية والقيم المتبقية للأصول.
   - مخصصات القضايا والنزاعات القانونية والتزامات الضمان (IAS 37).
6. **إيضاحات تفصيلية مساندة لكل بند من بنود القوائم المالية (تفاصيل الـ 16 بنداً الإلزامية).**
7. **إدارة المخاطر المالية (Financial Risk Management - IFRS 7):**
   - مخاطر السوق (Market Risk): مخاطر أسعار الصرف، مخاطر أسعار الفائدة.
   - مخاطر الائتمان (Credit Risk): مصفوفة أعمار الديون، تركيزات العملاء، والضمانات.
   - مخاطر السيولة (Liquidity Risk): جدول استحقاق التدفقات النقدية التعاقدية غير المخصومة للالتزامات.
8. **المعاملات مع الأطراف ذات العلاقة (Related Party Disclosures - IAS 24):** مكافآت ومزايا الإدارة العليا، والتعاملات مع الشركات الزميلة والمساهمين الرئيسيين.
9. **الالتزامات المحتملة والارتباطات الرأسمالية (Contingent Liabilities & Capital Commitments - IAS 37).**
10. **الأحداث اللاحقة لتاريخ التقرير (Events after the Reporting Period - IAS 10):** التمييز بين الأحداث المعدلة (Adjusting Events) وغير المعدلة (Non-adjusting Events).

### القوانين الرياضية التبادلية (The Inter-Statement Invariants)

1. **قانون ربط الأرباح بالملكية (P&L to Equity Invariant):**
   $$\text{Retained Earnings}_{t} = \text{Retained Earnings}_{t-1} + \text{Net Profit}_{t} - \text{Dividends Declared}_{t} \pm \text{Transfers}_{t}$$

2. **قانون ربط الدخل الشامل الآخر بالاحتياطيات (OCI to Reserves Invariant):**
   $$\text{AOCI Reserve}_{i, t} = \text{AOCI Reserve}_{i, t-1} + \text{OCI Component}_{i, t} - \text{Reclassifications to P\&L}_{i, t}$$

3. **قانون توازن التدفقات النقدية مع المركز المالي (Cash Flow to Balance Sheet Invariant):**
   $$\Delta \text{Cash} = \text{Operating Cash Flow} + \text{Investing Cash Flow} + \text{Financing Cash Flow} + \text{FX Effect on Cash}$$
   $$\text{Cash and Cash Equivalents (Balance Sheet)}_{t} = \text{Cash}_{t-1} + \Delta \text{Cash}$$

4. **معادلة تسوية الأرباح بالتدفق التشغيلي (Operating Cash Flow Reconciliation):**
   $$\text{CFO} = \text{Net Income} + \text{Non-Cash Expenses} - \text{Non-Cash Revenues} - \Delta \text{Non-Cash Working Capital} + \text{Non-Operating Items in P\&L}$$

## 6. المعايير الرقمية الدولية وأدوات الترميز (XBRL, ISO & Digital Reporting)

### 6.1 لغة تقارير الأعمال القابلة للتوسيع (eXtensible Business Reporting Language - XBRL)

- تعتمد جميع هيئات الأسواق المالية العالمية (مثل SEC الأمريكية، و ESMA الأوروبية، والهيئات المالية الخليجية) على صيغ **iXBRL (Inline XBRL)** لتقديم القوائم المالية رقمياً.
- **IFRS Taxonomy:** قاموس موحد تطلقه مؤسسة IFRS سنوياً يحتوي على آلاف العناصر (Tags) البرمجية التي تمنح كل بند في القوائم المالية هوية فريدة ومعنى حاسوبياً مقروءاً آلياً (Machine-Readable Semantic Identity).
- خصائص عنصر تاكسونومي XBRL:
  - `name`: الاسم التقني للبند (مثال: `PropertyPlantAndEquipment`).
  - `periodType`: نوع الفترة (`instant` للرصيد في المركز المالي، أو `duration` للحركة في قائمة الدخل والتدفقات).
  - `balance`: الطبيعة الحسابية (`debit` أو `credit`).
  - `substitutionGroup`: الموقع ضمن العناصر الأساسية.

### 6.2 معايير الأيزو المالية المكملة

- **معيار ISO 4217:** المعيار العالمي لترميز العملات؛ يحدد كود العملة الثلاثي المكون من أحرف أبجدية (مثل `USD`, `EUR`, `SAR`)، والرمز الرقمي، وعدد الخانات الكسرية (Minor Units)، وهو حاسم لمنع أخطاء التقريب وتخزين المبالغ بصيغة الأعداد الصحيحة الكبيرة (Integers/Micros).
- **معيار ISO 20022:** المعيار العالمي للرسائل المالية البنكية الإلكترونية المستخدم في المدفوعات والتسويات البنكية الدولية ومطابقة كشوف الحسابات الآلية (Bank Feeds Reconciliation) مع دفاتر الأستاذ العام (General Ledger).

## 7. متطلبات التدقيق والرقابة الداخلية (Auditability & COSO Framework)

لضمان اعتماد القوائم المالية من قِبل مدققي الحسابات الخارجيين ومؤسسات التصنيف، يجب أن يوفر النظام المحاسبي:

1. **مسار تدقيق غير قابل للتلاعب (Immutable Audit Trail - SOC-1 / ISAE 3402):**
   - حظر التعديل أو الحذف المباشر لأي قيد مرحل (`UPDATE` أو `DELETE` في قاعدة البيانات).
   - توثيق كل تعديل عبر قيود عكسية وتصحيحية نظامية (Reversing Entries) مع حفظ هوية المستخدم وتاريخ ووقت المعاملة (Timestamped Identity).
2. **الفصل بين الصلاحيات (Segregation of Duties - SoD & Maker-Checker):**
   - منع المستخدم الذي يُنشئ مسودة القيد من ترحيلها بنفسه.
   - التحقق من صلاحيات اعتماد التسويات الآلية للعملات، وإقفالات الفترات، وإهلاك الأصول.
3. **أرشفة الوثائق الثبوتية الرقمية (Documentary Support Attachment):**
   - ربط كل حركة محاسبية بالوثيقة الرقمية المصدرية (فاتورة إلكترونية معتمدة، إشعار استلام بضاعة GRN، عقد إيجار).

    'BS_EQUITY_SHARE_CAPITAL',

    'BS_EQUITY_RETAINED_EARNINGS',
    'BS_EQUITY_NCI',
    
    -- IFRS 18 P&L Categories
    'PL_OPERATING_REVENUE',
    'PL_OPERATING_EXPENSE',
    'PL_INVESTING_INCOME',
    'PL_INVESTING_EXPENSE',

    entry_date DATE NOT NULL,
    period_id UUID NOT NULL,
    status VARCHAR(20) NOT NULL CHECK (status IN ('DRAFT', 'POSTED', 'REVERSED')),
    description TEXT,
    created_by UUID NOT NULL,
    posted_by UUID,
    posted_at TIMESTAMPTZ,
    hash_checksum CHAR(64) NOT NULL, -- SHA-256 Chain
    prev_hash_checksum CHAR(64),
    CONSTRAINT uk_org_entry UNIQUE (org_id, entry_number)
);

CREATE TABLE journal_lines (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    entry_id UUID NOT NULL REFERENCES journal_entries(id) ON DELETE RESTRICT,
    account_id UUID NOT NULL REFERENCES chart_of_accounts(id),
    debit_amount_cents BIGINT NOT NULL DEFAULT 0, -- Minor units (Integers)
    credit_amount_cents BIGINT NOT NULL DEFAULT 0,
    currency CHAR(3) NOT NULL, -- ISO 4217
    exchange_rate NUMERIC(18, 8) NOT NULL DEFAULT 1.0,
    base_debit_cents BIGINT NOT NULL DEFAULT 0,
    base_credit_cents BIGINT NOT NULL DEFAULT 0,
    CONSTRAINT chk_positive_amounts CHECK (debit_amount_cents >= 0 AND credit_amount_cents >= 0),
    CONSTRAINT chk_one_sided CHECK ((debit_amount_cents > 0 AND credit_amount_cents = 0) OR (credit_amount_cents > 0 AND debit_amount_cents = 0))
);

### 8.2 الخوارزمية الرياضية لتوليد القوائم في محرك Go

```go
package reporting

import (
 "context"
 "fmt"
)

// FinancialStatementGenerator يمثل محرك التقارير المالية المتوافق مع IFRS 18 و IAS 1
type FinancialStatementGenerator struct {
 repo LedgerRepository
}

// GenerateIncomeStatement توليد قائمة الأرباح أو الخسائر وفق الفئات الخمس لمعيار IFRS 18
func (gen *FinancialStatementGenerator) GenerateIncomeStatement(
 ctx context.Context, 
 orgID string, 
 startDate, endDate string,
) (*IFRS18IncomeStatement, error) {
 // 1. استخراج الأرصدة التراكمية للحسابات خلال الفترة
 balances, err := gen.repo.GetPeriodCategoryBalances(ctx, orgID, startDate, endDate)
 if err != nil {
  return nil, fmt.Errorf("failed to fetch category balances: %w", err)
 }

 stmt := &IFRS18IncomeStatement{
  OrgID:     orgID,
  StartDate: startDate,
  EndDate:   endDate,
 }

 // 2. تجميع الفئات الخمس بدقة متناهية
 stmt.OperatingRevenue = balances.Sum("PL_OPERATING_REVENUE")
 stmt.OperatingExpenses = balances.Sum("PL_OPERATING_EXPENSE")
 stmt.OperatingProfit = stmt.OperatingRevenue - stmt.OperatingExpenses // إجمالي إلزامي أول

 stmt.InvestingIncome = balances.Sum("PL_INVESTING_INCOME")
 stmt.InvestingExpenses = balances.Sum("PL_INVESTING_EXPENSE")
 stmt.ProfitBeforeFinancingAndTax = stmt.OperatingProfit + (stmt.InvestingIncome - stmt.InvestingExpenses) // إجمالي إلزامي ثان

 stmt.FinancingExpenses = balances.Sum("PL_FINANCING_EXPENSE")
 stmt.ProfitBeforeTax = stmt.ProfitBeforeFinancingAndTax - stmt.FinancingExpenses

 stmt.IncomeTaxExpense = balances.Sum("PL_TAX_EXPENSE")
 stmt.ProfitFromContinuingOps = stmt.ProfitBeforeTax - stmt.IncomeTaxExpense

 stmt.DiscontinuedOperations = balances.Sum("PL_DISCONTINUED_OPERATIONS")
 stmt.NetProfitOrLoss = stmt.ProfitFromContinuingOps + stmt.DiscontinuedOperations

 // 3. احتساب بنود الدخل الشامل الآخر OCI
 stmt.OCINonReclassifiable = balances.Sum("OCI_NON_RECLASSIFIABLE")
 stmt.OCIReclassifiable = balances.Sum("OCI_RECLASSIFIABLE")
 stmt.TotalOCI = stmt.OCINonReclassifiable + stmt.OCIReclassifiable

 stmt.TotalComprehensiveIncome = stmt.NetProfitOrLoss + stmt.TotalOCI

 return stmt, nil
}
```
